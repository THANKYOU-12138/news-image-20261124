One image that sums up Tuesday 24 November 2026: a world-map front page drawn entirely by this program — no image assets. The masthead carries the date; ten numbered dots on a hand-drawn world map mark where each story happened — three tankers hit mines in the Strait of Hormuz, Russian jets enter Korea's air defence zone, the Indonesia factory fire toll reaches 26, Kyiv defends its Libya strike, Israeli strikes in Gaza, fighting traps Ebola teams in DR Congo, Baghdad seizes Kurdish oilfields, the EU's 22nd sanctions round, Nvidia cooling after a +31% day, and the UK sanctioning Myanmar generals. The renderer, bitmap font and PNG encoder are all hand-written in main.ts (Node stdlib only), so the 1024×1024 output is byte-identical on every run.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

Writes entry.png (1024×1024, ~23 KB) to the output directory — /output in the grader's container.
